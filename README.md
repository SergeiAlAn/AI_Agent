# Локальный AI-агент (ProxyAPI + LangChain)

Терминальный AI-агент, который понимает задачи на естественном языке, сам выбирает нужный инструмент
(поиск в интернете, погода, курсы валют и криптовалют, акции Мосбиржи, файлы, команды терминала)
и помнит контекст разговора между запусками.

Модель — `gpt-5-mini` через [ProxyAPI](https://proxyapi.ru) (OpenAI-совместимый API, работает из РФ),
агентная логика — [LangChain](https://python.langchain.com) (`create_agent`, tool calling).

```text
Вы: Какая погода в Казани и сколько стоит биткоин в рублях?

Агент:
В Казани сейчас +9.4 °C, пасмурно; Bitcoin стоит 6 650 000 RUB.
- Погода (Open-Meteo, 23:00): ветер 14 км/ч, северо-западный
- Bitcoin (CoinGecko): 6 650 000 RUB

  (7.2 c | инструменты: get_weather, get_crypto_price)
```

## Возможности

| Инструмент | Что делает | Источник |
|---|---|---|
| `web_search` | Поиск в интернете | DuckDuckGo / Yahoo через `ddgs` |
| `fetch_webpage` | Текст веб-страницы без HTML | `requests` |
| `http_request` | GET/POST/HEAD к публичным API | `requests` |
| `read_file`, `write_file`, `list_directory` | Работа с файлами в `agent/workspace/` | файловая система |
| `run_terminal_command` | Безопасные команды из белого списка | `subprocess` |
| `get_weather` | Текущая погода по названию города | [Open-Meteo](https://open-meteo.com) + геокодинг |
| `get_crypto_price` | Цена криптовалюты в любой валюте | [CoinGecko](https://www.coingecko.com/en/api) |
| `get_currency_cb_rate` | Официальный курс ЦБ РФ на дату | [cbr.ru XML_daily](https://cbr.ru/development/SXML/) |
| `get_share_price` | Цена акции на Мосбирже (по тикеру или названию) | [MOEX ISS](https://iss.moex.com/iss/reference/) |

Поведение агента:
- анализирует задачу и вызывает инструменты (при необходимости несколько подряд);
- если не хватает критичных данных (например, «Какая погода?» без города) — задаёт один уточняющий вопрос,
  но сначала проверяет память: если город уже известен, использует его;
- после каждого ответа сохраняет диалог и обновляет краткое резюме в `memory.json`;
- отвечает структурированно, с указанием источника и времени данных.

## Установка и запуск

Нужен Python 3.10+ и ключ ProxyAPI ([получить](https://console.proxyapi.ru/keys)).

```bash
cd agent
python -m venv .venv

# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

Создайте файл настроек и впишите ключ:

```bash
# Windows
copy .env.example .env
# Linux / macOS
cp .env.example .env
```

```ini
PROXIAPI_KEY=ваш-ключ
```

Запуск:

```bash
python run.py                              # интерактивный режим
python run.py -v                           # + показывать шаги агента в консоли
python run.py -q "Сколько стоит Bitcoin?"  # один вопрос и выход
```

> На Windows команда `python` может открывать Microsoft Store. Активируйте виртуальное окружение
> или используйте `py` вместо `python`.

### Команды внутри чата

| Команда | Действие |
|---|---|
| `/help` | справка |
| `/memory` | показать резюме из долговременной памяти |
| `/clear` | очистить память |
| `/tools` | список инструментов |
| `/exit` | выход (также `exit`, `quit`, Ctrl+C) |

### Примеры запросов

- Какая погода в Санкт-Петербурге?
- Сколько стоит Bitcoin? А Ethereum в рублях?
- Курс доллара и евро ЦБ РФ на 01.09.2026
- Сколько стоят акции Сбербанка и Газпрома?
- Найди, что нового в Python 3.14, и сохрани краткую сводку в файл python314.md
- Покажи файлы в рабочей папке

## Настройки (`agent/.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PROXIAPI_KEY` | — | ключ ProxyAPI (также принимаются `PROXYAPI_KEY`, `OPENAI_API_KEY`) |
| `PROXYAPI_BASE_URL` | `https://api.proxyapi.ru/openai/v1` | адрес OpenAI-совместимого API |
| `AGENT_MODEL` | `openai/gpt-5-mini` | модель (префикс `openai/` для этого адреса отбрасывается) |
| `AGENT_REASONING_EFFORT` | `low` | глубина рассуждений для gpt-5 / o-моделей: `minimal`, `low`, `medium`, `high` |
| `AGENT_SEARCH_BACKENDS` | `yahoo:wt-wt,yahoo:ru-ru,duckduckgo:ru-ru,auto:ru-ru` | порядок поисковых бэкендов `ddgs` |
| `AGENT_CONTEXT_MESSAGES` | `12` | сколько последних сообщений передавать модели |
| `AGENT_WORKSPACE` | `agent/workspace` | рабочая папка для файлов и команд |

## Безопасность

- **Файлы** — чтение и запись только внутри `agent/workspace/`; выход за её пределы (`../.env`) блокируется.
- **Терминал** — только белый список команд (`dir`, `ls`, `type`, `cat`, `echo`, `ping`, `ipconfig`,
  `pip list`, `git status` и т.п.). Запрещены операторы `& | ; > < $ % ( )`, аргументы с `..` и абсолютными
  путями; таймаут 30 секунд; команды выполняются в `workspace/`.
- **HTTP** — только `http/https`, методы GET/POST/HEAD; запросы к `localhost` и локальной сети блокируются.
- **Секреты** — ключ хранится только в `agent/.env`, который исключён из git.

## Логирование и отладка

Все действия пишутся в `agent/logs/agent.log` (ротация по 2 МБ, 3 файла):
запрос пользователя, выбранные агентом инструменты и аргументы, результат и время каждого инструмента,
итоговый ответ, полные трейсбеки ошибок. В консоли ошибки показываются одной строкой; с флагом `-v`
видны и все шаги агента.

Проверить инструменты без обращения к LLM (тратит 0 токенов):

```bash
python test_tools.py
```

## Известные ограничения

- Бесплатный поиск через `ddgs` нестабилен: из РФ DuckDuckGo часто отвечает пусто, поэтому агент
  перебирает несколько бэкендов и упрощает запрос. Поиск возвращает только сниппеты — для деталей агент
  открывает страницу через `fetch_webpage`.
- Сайты, которые строят содержимое JavaScript'ом (например, интернет-магазины вроде 5ka.ru),
  отдают программам пустую страницу — цены с них получить нельзя.
- CoinGecko без ключа ограничивает частоту запросов (около 30 в минуту).
- Курс ЦБ РФ публикуется по рабочим дням; на выходные действует курс последнего рабочего дня —
  агент сообщает, на какую дату он установлен.
